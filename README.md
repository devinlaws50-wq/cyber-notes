## About Me

I am a Systems Administrator developing deeper expertise in cloud infrastructure and security engineering.

My portfolio focuses on building and securing hands-on environments across Microsoft Azure and AWS. I use Terraform to deploy infrastructure, Active Directory and Group Policy to manage identity and Windows systems, and Microsoft Sentinel and Splunk to monitor authentication activity and investigate security events.

Each project documents the architecture, implementation process, security decisions, validation steps, and troubleshooting involved in building the environment.

My current focus areas include:

- Azure infrastructure and network security
- Infrastructure as Code with Terraform
- Active Directory and Windows Server administration
- Microsoft Sentinel, KQL, and security monitoring
- Splunk log analysis and dashboard development
- Azure governance, RBAC, and policy enforcement
- Cloud automation and CI/CD
